# 給与の学び舎 — 2026年度版・2級

給与計算実務能力検定2級の演習アプリ。TanStack Start安定版 + React + TypeScript + Nitroで実装し、Vercel向けに構成しています。

## 起動

Node.js 24以上。

```sh
npm ci
npm run dev
```

http://localhost:3000 を開きます。

## 学習機能

- 2026年度版のオリジナル問題64問（知識34問・計算30問）。四肢択一、解説・計算式付き。
- ジャンルと6分野の絞り込み、検索、ブックマーク。
- FSRS-7（ts-fsrs）で問題ごとの記憶の安定度・難易度を更新。目標保持率90%、初期学習ステップ1分・10分、再学習10分、fuzz無効。
- 誤答は必ずAgain。正答時はAgain / Hard / Good / Easyの自己評価を反映し、各ボタンに次回間隔を表示。
- 期限到来順に復習問題を優先し、その後に未学習問題を出題。1回最大10問。期限前の問題はライブラリから任意に練習可能。
- 学習記録、正答率、7日間の回答数、連続学習、1日の目標。日付は日本時間。
- 演習画面から開ける四則演算のポップアップ電卓。問題文をスクロールしながら利用でき、見出しをドラッグして移動可能。小数・クリア・1文字削除に対応。法令基準日の右側のボタンから開く。スマホの数字キーは通常50px、画面高700px以下では48px。
- localStorageにカード・回答履歴・ブックマーク・目標を保存。JSONバックアップの書き出し・検証付き復元。
- メイリオ優先のフォントと、装飾を抑えた演習中心の画面。スマホを優先し、通常画面の下部ナビ、演習中の集中表示、回答ボタンのsticky表示、タッチ操作用の大きな選択肢。

クラウド同期・ログイン・サーバーDBは未実装です。ブラウザのデータを消すと履歴が失われるため、設定からバックアップできます。FSRSの個人パラメータ最適化は未実装で、既定パラメータによる問題単位の間隔調整を行います。

## 2026年度の教材方針

2026年11月試験を想定し、法令基準日を **2026年9月1日** としています。公的情報の調査確認日は2026年11月1日。

[主催団体の2級案内](https://fos.or.jp/shikaku/pc2/)と[認定団体の出題範囲](https://jitsumu-up.jp/about/)をもとに、通常の給与・賞与・社会保険・勤怠・労働法令を出題。年末調整の計算は収録しません。公式問題の転載ではありません。公開の公式資料集は2023年度版のため、形式確認のみに使い、2026年度の料率根拠にはしていません。公式テキストの全文照合は未実施で、本試験への完全準拠や出題的中を保証するものではありません。

料率・税額の条件は各問題に明記。2026年度の根拠と更新方法は [docs/content-policy.md](docs/content-policy.md) に記載しています。健康保険医療分は全国一律ではありません。

## 検証

```sh
npm run typecheck
npm test
npm run build
NITRO_PRESET=vercel npm run build
```

FSRSの正誤反映・期限順序・永続化後の再回答・日本時間の日付・バックアップ検証と、問題データの整合性・複合計算の答えをテストします。

ローカルサーバーを起動し、Chromeがある環境では次の実操作チェックも実行できます。

```sh
node scripts/browser-check.mjs
```

画面幅360 / 390 / 430 / 768 / 1440px、ジャンル選択、回答・理解度、再読み込み後の履歴、検索を確認します。スクリーンショットはOSの一時ディレクトリに出力します。

## Vercelへの公開

VercelのNode.js設定を **24.x** にして、このリポジトリをImportします。`vercel.json`でTanStack Startを指定済み。環境変数・外部DBは不要です。

CLIを使う場合：

```sh
npx vercel login
npm run deploy
```

この作業環境はVercelに未ログインだったため、本番公開は行っていません。Vercelの出力をローカルで確認するには `NITRO_PRESET=vercel npm run build` を実行します。

## 主なファイル

- `src/routes/index.tsx` — TanStack Routerのルート登録のみ
- `src/features/study/study-app.tsx` — 画面切り替えと各機能の接続
- `src/features/study/screens/` — ホーム・演習・ライブラリ・学習記録・設定
- `src/features/study/components/` — 問題カード、解説、ジャンル選択、バックアップ等
- `src/features/study/hooks/use-study-data.ts` — 履歴保存・復元・目標・ブックマーク
- `src/features/study/hooks/use-study-session.ts` — 出題・解答選択・理解度評価・次問への遷移
- `src/lib/study-summary.ts` — 回答履歴を日本時間の日付で集計する純粋関数
- `src/lib/study.ts` — FSRS・出題キュー・永続化データ
- `src/lib/questions.ts` — 問題型・年度情報・問題集の統合
- `src/lib/questions-2026.ts` — 2026年度の知識・計算問題と根拠リンク
- `src/styles.css` — レスポンシブUI

画面コンポーネントはpropsでデータと操作を受け取ります。履歴の保存処理と演習中の一時状態は別のフックで管理し、画面の切り替えで検索条件や演習状態が失われないよう、フックは `StudyApp` に置いています。
